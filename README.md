# PinkBeats 🎶

Um site inspirado no universo do K-pop, com destaque para:
- Yves (ex-LOONA, comeback LOOP)
- NewJeans
- Illit
- ITZY  

## Estrutura
- `index.html`: Página principal com galeria e seção sobre.
- `styles.css`: Estilos em azul claro.
- `script.js`: Script básico para interatividade.
- `images/`: Pasta com imagens usadas.

## Como usar
1. Coloque todas as imagens na pasta `images/`.
2. Abra o `index.html` no navegador.
3. Aproveite a vibe PinkBeats
